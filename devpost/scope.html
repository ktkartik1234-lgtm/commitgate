Proof-of-Work Verifier

Local CLI, Git post-commit verification engine, and minimalist HTML "Trusted Proxy" status widget backed by SQLite.

doc: scope • status: approved

The Unique Kernel

Deterministic, zero-trust Git commit verification triggered automatically by a local post-commit hook, persisted in SQLite, and surfaced live in a minimalist local HTML status widget.

Pass/fail decisions are 100% rule-based (commit existence, session ID match, hook SHA record, expected files touched, non-noise diff, and passing test exit code)—never willpower or LLM vibes.

Who It's For & Why It Matters

Built for a developer spending up to 15 hours/day at a laptop who wants invisible, non-negotiable accountability tied to verifiable code output.

Inspirations: Local Git hooks, VS Code API, Cold Turkey (strict enforcement), and Obsidian (local-first state).

Scope Boundary Explorer (Now / Later / Cut)

  • NOWCLI commands to initialize the Git hook, start a session with rules, and inspect status.
  • NOWSQLite database persisting session ID, rules, hook commit events, and verification results.
  • NOWAutomatic Git post-commit hook capturing commit SHA and triggering deterministic verification.
  • NOWDeterministic rule engine (commit exists, session ID in message, hook SHA match, target file touched, non-noise diff, test command exit 0).
  • NOWMinimalist local HTML "Trusted Proxy" status widget showing live PENDING → REJECTED → VERIFIED transitions.
  • LATERLLM coaching or feedback layered strictly after deterministic pass/fail verification.
  • LATERBrowser extension for tab unlocking or YouTube active-recall ("pause & prove what you learned").
  • LATEREmail / job-application "Trusted Proxy" inbox monitor.
  • LATERLong-running multi-agent orchestration, VS Code API integration, and non-Git file watchers.
  • CUTVibes-based LLM pass/fail judgment: LLMs can hallucinate or be prompt-injected; proof-of-work verification must be 100% deterministic.
  • CUTCloud sync, user accounts, and bloated web dashboards: Kept 100% local-first and distraction-free for a 2–4 hour build.
